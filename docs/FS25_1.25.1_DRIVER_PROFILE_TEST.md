# FS25 1.25.1.0: Experimental 5X / 6X driver-profile test

This is a **driver override test**, not an EXE patch. It does **not** add 5X/6X to the game's graphics menu, and it does not guarantee functional 5X/6X on this game build.

The legacy on-disk EXE patch is blocked for 1.25.1.0: old signatures 0/7 matched, and forcing old offsets led to Steam error 51. No unknown binary layout will be patched.

## Prerequisites

- RTX 40/50 GPU and a sufficiently recent NVIDIA driver.
- RTX 40: user-supplied Native DLSS MFG for Ada GPUs helper (Nexus mod 2038). Verify that version.dll really exists alongside x64/FarmingSimulator2025Game.exe. Vortex "Enabled" alone is not proof.
- NVIDIA Profile Inspector, from https://github.com/Orbmu2k/nvidiaProfileInspector/releases
- A compatible game DLSS Frame Generation / Streamline runtime. The observed FS25 1.25.1.0 has sl.dlss_g.dll **2.7.32.0**; 5X/6X may require Streamline 2.11+ or another matching, tested runtime. Do NOT replace individual Streamline DLLs blindly.

## Test

1. Back up the existing Farming Simulator 25 profile in NVIDIA Profile Inspector (Export). The profile must already contain FarmingSimulator2025Game.exe.
2. Run the new test build. Select the original FS25 game EXE.
3. Select EXPORT 5X PROFILE or EXPORT 6X PROFILE. Enter the **exact existing** NPI profile name, save the .nip file.
4. In NVIDIA Profile Inspector, import .nip using **MERGE**; never use REPLACE.
5. Verify only these settings were added/changed: 0x10308298 = 2 (Fixed mode) and 0x104D6667 = 4 for 5X or 5 for 6X.
6. Restart FS25, enable an existing DLSS Frame Generation mode in-game (the menu may still say 2X/3X/4X), and compare *real rendered* vs *generated* frames. A high FPS number alone does not confirm genuine MFG.
7. Restore the saved original NPI profile to undo.

The exporter NEVER modifies game executable, game.xml, driver settings or third-party DLLs. It only writes a human-inspectable NPI XML fragment with two DWORD settings and zero executable reassignment entries. The game/driver/helper may still reject the override.

Technical references: NVIDIA NVAPI NvApiDriverSettings.h, the MIT-licensed Orbmu2k nvidiaProfileInspector source (.nip XML import format), and Nexus Mods 2038. No third-party DLL is bundled.
